# 可行复用改进

依据主工作区的高层重构方案和共用声明原型验证报告，只实施已有同义行为证据的部分。保留全部导航、Action、公开投影和资源生命周期能力；不采用净增代码且破坏声明快照的原型。

## 实施与验收

1. full/minimal 各以现有 React 模板的中立源码为唯一维护源，物化 Vue/Svelte 副本。保留原生视图、入口、配置与独立 appId。安装、构建、开发启动和发布准备同步源码；生成器拒绝覆盖本地修改。发布产物移除仓库内部钩子，六种应用均可在仓库外独立安装和构建。
2. beforeLoad/afterLoad 使用同一个泛型守卫循环；保留两个公开入口、输入类型、前后取消检查与首个非 next 短路。Web 非阻塞观察者共用私有通知函数；提交步骤和日志 sink 的错误语义不改变。
3. 按用户要求先实施后测试。补充守卫取消、观察者隔离与模板生成边界验证，执行 vp check、完整测试、构建、原生浏览器和六模板独立消费者验证。最后进行独立差异审查。
4. 分别统计运行时净减量、模板维护源净减量，以及生成器和验证成本。物化后的应用代码不冒充被删除的运行时代码。验证通过后将增量应用回主工作区，保留其原有未提交修改。
