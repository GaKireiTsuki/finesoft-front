# @finesoft/front

Portable operations and explicit Web, browser, SSR, HTTP, Node, Worker and Vite entries. React, Vue and Svelte use optional native Outlet bindings.

```bash
vp dlx @finesoft/create-app my-app
```

[English guide](./docs/README.md) · [简体中文](./docs/zh/README.md)

Import general execution from `@finesoft/front`; select `/web`, `/browser`, `/ssr`, `/http`, `/node`, `/worker` or `/vite` for the corresponding environment. Native UI bindings use `/react`, `/vue` or `/svelte`; applications own their native mount and SSR render. Install only the peer dependencies for the entries you use.
