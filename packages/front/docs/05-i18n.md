# Locale and messages

Keep messages in application declarations and request locale in the invocation. The browser target owns locale attributes for its instance.

## Configuration / 配置

```ts
import { loadMessages } from "virtual:finesoft-front/i18n-loader";
// defineWebApp({ ..., loadMessages, frameworkConfig: { locale: "zh-Hans" } })
// finesoftFrontViteConfig({ ..., i18n: { messagesDir: "src/locales" } })
```

Enable the Vite loader only when using locale files. It avoids an eager import of every language in the browser. Controllers read the configured translator through `DEP_KEYS.LOCALE` / the framework dependencies as appropriate; do not mutate a process-wide locale during concurrent requests. Portable callers may pass `{ locale }` to `runtime.execute`.
