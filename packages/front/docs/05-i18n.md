# Locale and messages

Keep messages in application declarations and request locale in the invocation. The browser target owns locale attributes for its instance.

## Configuration / 配置

```ts
import { loadMessages } from "virtual:finesoft-front/i18n-loader";
// defineWebApp({ ..., loadMessages, configuration: { locale: "zh-Hans" } })
// finesoftFrontViteConfig({ ..., i18n: { messagesDir: "src/locales" } })
```

Enable the Vite loader only when using locale files. It avoids an eager import of every language in the browser. Read the configured translator with `app.translator` in native views or `await context.get(DEP_KEYS.TRANSLATOR)` in operations. `app.locale` / `DEP_KEYS.LOCALE` provide `{ lang, dir }` attributes; do not mutate a process-wide locale during concurrent requests. Portable callers may pass `{ locale }` to `runtime.execute`.
