# 语言与文案

文案加载放在应用声明，请求语言放在 invocation。浏览器语言属性属于各自的挂载目标。

## Configuration / 配置

```ts
import { loadMessages } from "virtual:finesoft-front/i18n-loader";
// defineWebApp({ ..., loadMessages, frameworkConfig: { locale: "zh-Hans" } })
// finesoftFrontViteConfig({ ..., i18n: { messagesDir: "src/locales" } })
```

使用语言文件时启用 Vite loader，避免浏览器提前导入所有语言。通过框架依赖读取配置，勿在并发请求中修改进程级语言。可移植调用可向 `runtime.execute` 传入 `{ locale }`。
